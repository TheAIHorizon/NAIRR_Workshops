NAIRR Workshop · Build Your Own

Notebook Ideas to Ask the AI to Build

AI × cybersecurity projects you can have an AI assistant build for you and run on NAIRR / Jetstream2 — for the classroom or your research.

Each idea below comes with the plain-English request you'd type to your AI assistant (see the setup guide). The pattern is always the same: describe it → the AI builds the notebook → you run it on NAIRR. Green = runs on a basic CPU instance; red = worth spinning up a GPU. Copy a prompt and try one!

CPU Runs on a basic instance (no GPU needed)

Classic machine learning and small models — anyone can run these on the default m3.quad.

Phishing email detector

Train a classifier on labeled emails, then paste one in to score it.

Build a notebook that trains a phishing-email classifier on a public dataset and lets me paste an email to get a phishing probability, with the top words that influenced the score.

Log anomaly detection

Flag unusual auth/web-server log entries with an Isolation Forest.

Make a notebook that loads sample auth logs and flags anomalous login events, with a chart of when they happened.

Intrusion detection on a classic dataset

Classify benign vs. attack traffic on NSL-KDD or UNSW-NB15.

Build an intrusion-detection notebook on the NSL-KDD dataset comparing a few models and showing accuracy and a confusion matrix.

Malware classification from static features

Train on PE-header / feature datasets — no live malware involved.

Create a notebook that classifies malware vs. benign from a static-features dataset and explains which features matter most.

CVE triage & clustering

Group and prioritize vulnerability descriptions with TF-IDF + clustering.

Build a notebook that takes CVE descriptions, clusters them by topic, and flags the ones that look high-severity.

IOC / threat-intel extractor

Pull IPs, hashes, domains, and CVEs out of unstructured reports.

Make a notebook that extracts indicators of compromise from a pasted threat report into a clean table.

Password security analysis (educational)

Study leaked-password patterns, entropy, and estimated crack times to teach better policy.

Build a notebook that analyzes common password patterns and estimates crack times to illustrate why length beats complexity.

SOC log dashboard

Parse logs, geolocate source IPs, and chart failed-login spikes over time.

Create a notebook that turns a log file into a dashboard: failed logins over time, top source IPs, and a map.

GPU Worth spinning up a g3 / g4 / g5

Deep learning and language models — these show off what NAIRR's bigger resources unlock.

Local LLM as a SOC analyst assistant

Run a model that explains logs, summarizes CVEs, and drafts incident reports.

Build a notebook that runs a local LLM as a security assistant — I paste a log and it explains what happened and suggests next steps.

Fine-tune a transformer for security text

Adapt a small transformer to classify malicious vs. benign messages.

Fine-tune a small transformer to classify malicious vs. benign messages and report before/after accuracy.

Prompt-injection & jailbreak defense (educational)

Demonstrate attacks on an LLM and the guardrails that stop them.

Make a notebook that demonstrates prompt-injection against a local LLM and shows defensive techniques that block it.

AI-generated text / deepfake-text detection

Train or run a detector for machine-written content.

Build a notebook that detects AI-generated vs. human-written text and shows where it's confident or unsure.

Deep-learning intrusion detection

An autoencoder/CNN that learns "normal" traffic and flags deviations.

Create a notebook that trains an autoencoder on network traffic to detect anomalies, with a reconstruction-error chart.

Malware-as-image classification

Convert binaries to images and classify families with a CNN.

Build a notebook that turns malware byte data into images and trains a CNN to classify families.

Threat hunting with embeddings (semantic search / RAG)

Embed past incidents to find similar ones, or do Q&A over a security-docs corpus.

Make a notebook that embeds a set of incident reports, lets me search them by meaning, and answers questions about them.

Adversarial examples on an image model

Show how tiny perturbations fool a classifier — AI security & robustness.

Build a notebook that creates adversarial examples that fool an image classifier and shows the before/after.

★ Tie-in to AI Horizon

Directly on the theme of how AI is reshaping the cybersecurity workforce.

"Which security tasks will AI automate?"

Use an LLM to classify cybersecurity job tasks as created / replaced / augmented / human-driven.

Build a notebook that takes a list of cybersecurity job tasks and uses an LLM to label each as likely automated, augmented, or human-driven, with reasoning.
The point for your audience: every one of these is "describe it → the AI builds it → run it on NAIRR." You don't need to be a programmer — you need a good question. Pick one and ask the assistant to build it live.
