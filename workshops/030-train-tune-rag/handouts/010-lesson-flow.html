NAIRR Workshop 2 · Lesson Flow

Train vs. Tune vs. RAG

Three ways to make an AI model useful for your topic — built on the same model and knowledge, so you can see the difference for yourself.

The big idea

Train from scratch

The model learns everything from your data, starting from zero. Powerful but needs huge data + compute.

Fine-tune (LoRA)

Take a model that already knows language and adapt its behavior/format cheaply.

RAG

Change nothing in the model — retrieve relevant facts and hand them to it at question time.

The rule to remember: need new facts → RAG  ·  need new behavior/format → fine-tune  ·  need a brand-new capability → train (expensive — usually not worth it).
🧪

Why it's a fair fight

All approaches use the same base model, the same small knowledge corpus, and the same test questions. The corpus even contains a few private, fictional facts (a made-up "Redlake University" policy) that no pretrained model could know — so you'll see exactly where each method wins.
